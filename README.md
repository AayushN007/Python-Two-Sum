# Python Two Sum

A simple Python solution to find two numbers in an array whose sum equals a given target.

## Approach

The program checks every possible pair of elements using nested loops. If a pair adds up to the target, their indexes are returned.

## Concepts
- Lists
- Nested loops
- Indexing
- Functions
- Difference calculation

## Complexity

- Time: O(n²)
- Space: O(1)
